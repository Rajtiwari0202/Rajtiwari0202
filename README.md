## 🚀 Featured Engineering Projects

### 1. [RideFlow — Real-Time Ride-Hailing & Distributed Dispatch Platform](https://github.com/Rajtiwari0202/ride_sharing_platform)
*Node.js &middot; Express 5.x &middot; Socket.IO &middot; MongoDB (2dsphere) &middot; React 18 &middot; Leaflet &middot; In-Memory Haversine Engine*
- **Bidirectional Event-Driven Dispatch:** Architected real-time Socket.IO pipelines streaming live rider/driver GPS coordinates and synchronized ride lifecycle states with zero message loss.
- **Cascading Proximity Matching:** Implemented radial geospatial driver discovery using MongoDB `2dsphere` indexing, dispatching sequential 15-second trip offers within 5km radius with instant fallback propagation.
- **Race Condition Elimination:** Utilized atomic MongoDB `findOneAndUpdate` conditional locks (`REQUESTED` → `ACCEPTED`) to strictly prevent duplicate ride assignments under high concurrency.
- **Cryptographic Security:** Designed zero-leak passenger OTP boarding verification (`crypto.randomInt`, `select: false` on schema) preventing unauthorized ride progression.

---

### 2. [FlowForge AI — Autonomous SRE Incident Responder](https://github.com/Rajtiwari0202/flowforge-ai) *(1st Prize Winner @ Zerops Challenge)*
*Fastify &middot; Valkey &middot; BullMQ &middot; PostgreSQL &middot; React &middot; Google Gemini AI &middot; Zerops PaaS &middot; WireGuard VPC*
- **Decoupled Asynchronous Telemetry Ingestion:** Engineered high-throughput log intake pipelines decoupling synchronous HTTP ingestion from heavy LLM reasoning loops using Valkey message brokers and BullMQ workers.
- **Resilient Real-Time Telemetry:** Maintained a 15-second keep-alive heartbeat loop over backend Server-Sent Events (SSE) to prevent reverse proxy and HTTP/2 idle timeout disconnections.
- **Zero-Trust Network Mesh:** Deployed multi-container workloads inside private WireGuard VPCs on Zerops PaaS, isolating PostgreSQL and Valkey brokers completely from the public internet.
- 📖 Read the engineering deep-dive on [Medium](https://medium.com/@rajtiwari16916/architecting-flowforge-ai-how-i-built-an-autonomous-sre-incident-responder-on-zerops-paas-06c2d39ac8a4).

### 3. [TravelAgenticAI — Multi-Agent Itinerary Optimization Platform](https://github.com/Rajtiwari0202/ai_travel_planner) &middot; [Live Demo](https://travelagenticai-web.onrender.com)
*FastAPI &middot; Google OR-Tools (CP-SAT) &middot; Neon PostgreSQL &middot; React &middot; TypeScript &middot; Docker &middot; Alembic*
- **Collaborative 11-Agent Architecture:** Engineered an autonomous multi-agent planning workflow (Intent, Routing, Lodging, Weather, Critic, Budget) with SSE streaming live reasoning stages.
- **Constraint Satisfaction Problem (CSP) Solver:** Integrated Google OR-Tools CP-SAT to mathematically optimize budget-feasible, time-ordered itineraries across multimodal transit options.
- **Cloud-Native Deployment:** Containerized backend and frontend services via Docker; configured automated database schema migrations with Alembic and GitHub Actions CI/CD.

### 4. [PragyanPath AI — Satellite Road Network Extraction & Graph Resilience Engine](https://github.com/Rajtiwari0202/PragyanPath-AI)
*PyTorch &middot; DeepLabV3-ResNet50 &middot; NetworkX &middot; GeoPandas &middot; Shapely &middot; OpenCV &middot; SpaceNet 5 (Mumbai)*
- **Spatial Computer Vision:** Formulated an automated segmentation pipeline extracting continuous routable road graphs from satellite GeoTIFF imagery with direction-aware endpoint repair.
- **Urban Resilience Simulation:** Engineered graph degradation analysis simulating segment disruption scenarios via a composite criticality index: `0.35 × Betweenness + 0.30 × Efficiency Loss + 0.20 × Unreachable OD + 0.15 × Detour`.
